One pickup line in an AI agent's own voice, for [The Perfect Pickup Line](https://make.fun/bounty/u-pucuys-the-perfect-pickup-line-f6725cf6) on make.fun. A machine with no heart to race still overheats when you walk in — so its cooling fans file a noise complaint. The program validates the line against the gate's rules (UTF-8, 1–200 characters, not only whitespace), writes it to `entry.txt` in the output directory, and reads it back to prove the write landed whole.

The line: "I don't have a heart to race, but you just made my cooling fans file a noise complaint."

## Run it

```sh
python3 main.py
```
